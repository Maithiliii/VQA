# Visual Question Answering (VQA)
This is a simple web application that lets users upload an image and ask a question about it. The app uses a pretrained deep learning model to answer questions based on the content of the image.

🚀 Features  
Upload or drag-and-drop an image  
Ask a natural language question about the image  
View the model's predicted answer instantly  

🛠️ Tech Stack  
Frontend: HTML, CSS, JavaScript (jQuery)  
Backend: Python + Flask  
ML Model: dandelin/vilt-b32-finetuned-vqa (HuggingFace Transformers)  
Libraries: Transformers, Torch, Pillow
